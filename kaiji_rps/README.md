# Kaiji Restricted RPS — 限定猜拳（3D / Godot 4）

《赌博默示录·开司》船上「限定ジャンケン（限定猜拳）」的一个原创 3D 实现。
用 **Godot 4.x + GDScript** 写成，美术全部程序化生成（几何体 + 代码贴图），
不依赖任何外部素材，也不使用原作的角色 / 美术资源。

## 玩法规则

- 你和 5 名 AI 同桌，每人开局 **12 张牌**（石头/剪刀/布 各 4）、**3 颗星**、一些资金。
- 限时 **4 分钟**（原作 4 小时的压缩版），倒计时归零结束。
- 找一个对手单挑：各出一张牌，按猜拳比大小。
  - 赢家从输家手里 **拿走 1 颗星**；
  - 平局 **两张牌照样消耗**，但不转移星星（这正是危险之处）；
  - 不管胜负，两张出掉的牌都用掉了。
- **星星归零 → 破产出局。**
- **存活条件**：时间结束时，**12 张牌全部打光，且手里仍有 ≥3 颗星**。

### 完整经济系统

- **多名 AI** 各有性格（沉稳 / 好斗 / 谨慎 / 难测），会在后台互相单挑、买卖星、
  借钱还钱，桌面经济一直在流动，制造稀缺与压力。
- **动态星价**：星价不是固定的，随**时间紧迫度**和**星星稀缺度**浮动——越临近
  终局、桌上星星越少，买星越贵。买卖之间有价差（庄家抽水）。
- **借贷 + 利息**：现金不够可以**借钱**（每笔 100，上限 600）去买星周转，
  债务会**按时间复利滚动**，记得还。这还原了原作「债务地狱」的味道。
- **AI 主动开价**：对手会时不时找你**谈一笔星星买卖**（高于市价收你的星 / 低于
  市价卖你星），你可接可拒——一个真正的谈判层。
- **卡牌交易**：和选定对手 1 换 1，AI 按是否划算决定接不接。换牌不改变全场卡牌
  总数——封闭经济，牌只能靠对战打掉。
- **终局净资产排名**：按 `现金 + 星星估值 − 债务` 给所有人排名。
- 对手面板显示各自的「性格提示」，可据此猜它的出牌倾向——轻量心理博弈层。

## 运行方式

需要本地安装 [Godot 4.x](https://godotengine.org/)（建议 4.3+）。

1. 打开 Godot，`Import` 选择本目录下的 `project.godot`。
2. 直接按 `F5`（运行主场景）即可开玩。

### 操作

- 左侧 **OPPONENTS** 面板点一个对手 → 选定目标（牌桌上会高亮）。
- 底部 `Play R / Play S / Play P` → 用对应的牌和选定对手单挑。
- `Market / Trade` → 打开市场：买/卖星（价格动态）、借钱/还钱、和选定对手换牌。
- 弹出 **A DEAL IS OFFERED** 时 → AI 在向你开价，`Accept` / `Decline`。
- 左上角状态面板实时显示：剩余时间、星星、现金、债务、当前星价、净资产。
- `End Match Now` → 立即结算（按存活条件判定 + 净资产排名）。

## 工程结构

```
kaiji_rps/
├─ project.godot          # 工程配置，入口场景指向 scenes/main.tscn
├─ icon.svg               # 程序化图标
├─ game/                  # 纯逻辑层（不涉及渲染，可独立测试）
│  ├─ card.gd             # 三种牌的比较 / 颜色 / 字母
│  ├─ player.gd           # 一名玩家：手牌、星星、现金、债务、存活
│  ├─ ai_brain.gd         # AI 出牌（按性格加权）与换牌判断
│  └─ rps_game.gd         # 规则引擎 + 经济（对战、动态星价、借贷、报价、换牌、结算）
├─ scenes/
│  ├─ main.tscn           # 最小入口场景（只挂 main.gd）
│  └─ main.gd             # 用代码搭 3D 牌桌 + HUD + 对战流程
└─ tests/
   └─ test_rules.gd       # 无头规则测试
```

设计上 **逻辑层和表现层分离**：`game/` 完全不碰渲染，`scenes/main.gd` 通过
信号监听规则引擎。想加新功能（更强的 AI、多人、更细的市场）改起来不会牵一发动全身。

## 说明 / 已知限制

- 这套工程是在没有 Godot 可执行文件的环境里写出来的，**作者未能本地运行验证**。
  代码只用了把握较大的 Godot 4 API，但首次打开如果某行报错，多半是个别属性名的
  版本差异——逻辑层（`game/`）可先用上面的无头测试单独验证。
- 美术刻意做成极简（深色牌桌 + 聚光灯 + 红/蓝/金卡面 + 浮空标签）。
  后续可换成 CC0 素材（如 Kenney、glTF 模型）或加 `WorldEnvironment` 的辉光来提质感。
