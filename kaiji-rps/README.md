# 限定猜拳（Kaiji 限定ジャンケン）

《赌博默示录》中"希望之船 ESPOIR"上的限定猜拳游戏，纯 HTML/JS 单文件实现，无任何依赖。

## 怎么玩

直接用浏览器打开 `index.html` 即可。

## 规则

- 你和对手各持 **12 张卡**（石头 ×4、剪刀 ×4、布 ×4）和 **3 颗星**
- 每回合双方各出一张卡，出过的卡即作废
- 胜者从败者手中夺走 1 颗星；平局双方卡作废，星不变
- 双方打出过的卡都是公开情报，可据此推算对手剩余手牌
- 12 回合结束后 **星 ≥ 3 颗** 即生还；中途星归零直接出局

## AI 对手

对手会统计你剩余的手牌分布，选择期望收益最高的牌（带一定随机性），
所以越到后期、你的牌型越偏，它的出牌就越精准——管理好自己的牌型分布是取胜关键。
